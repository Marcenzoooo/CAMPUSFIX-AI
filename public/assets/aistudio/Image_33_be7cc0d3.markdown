## Brand & Style

The design system projects an intelligent, authoritative, yet thoroughly approachable operating system tailored for higher education ecosystems. It reconciles high-velocity enterprise infrastructure with student-friendly transparency. The visual language rejects juvenile collegiate aesthetics and dystopian, over-saturated cyber motifs in favor of **Executive Modern SaaS**—disciplined, modular, and crisp.

Key aesthetic characteristics:
- **Calibrated Vibrancy:** Uses an electric berry-pink primary tone with surgical restraint against deep midnight foundations and clean architectural planes.
- **Architectural Modularity:** Structural panels, precise hairline divisions, and subtle surface elevations emphasize data fidelity and continuous system uptime.
- **Atmospheric Warmth:** Soft ivory backdrops offset clinical starkness, balancing artificial intelligence capability with human warmth.

## Colors

The palette leverages high structural contrast with restrained accent distribution:

- **Primary Signature Pink (`#E84D96`):** The primary interaction anchor. Used for primary calls-to-action, key state indicators, critical real-time telemetry, and focused input states. Never used for massive planar fills.
- **Midnight Black (`#19171D`):** The grounding architecture. Applied to primary headings, high-priority icons, critical enterprise navigation chrome, and contrasting pills.
- **Soft Charcoal (`#302B35`):** Secondary typography, metadata, and segmented toolbars.
- **Warm Ivory Canvas (`#F8F6F7`):** The foundational ambient background, preventing clinical optical fatigue during extended workflows.
- **Card Surfaces (`#FFFFFF`):** High-layer elevation plane for functional cards, tables, modal bodies, and panels.
- **Cool Silver (`#E8E4E9`):** Precise 1px hairline borders, dividers, and framing rings.
- **Soft Rose (`#F8E7EF`):** Low-contrast tint for active pill states, subtle badge containers, and hover fills.
- **Semantic Roles:**
  - **Success (`#27866D`):** Sensor confirmation, resolution complete, green status.
  - **Warning / In-Progress (`#C58A32`):** Predictive flags, queued dispatch, pending approval.
  - **Critical Alert (`#C95765`):** Infrastructure failures, critical ticket escalation, offline node alerts.

## Typography

The typographic hierarchy pairs **Plus Jakarta Sans** for structural headlines with **Inter** for dense transactional UI, data visualization, and micro-copy:

- **Headlines (Plus Jakarta Sans):** Set with tight letter-spacing (`-0.01em` to `-0.03em`) to produce a clean, contemporary product presence. Used exclusively across dashboards, section headers, KPI summaries, and major display touchpoints.
- **Body & Controls (Inter):** Highly legible at small sizes across tables, logs, and ticket tracking.
- **Hierarchy Standard:** Use `label-sm` with uppercase transformation and slight tracking (`letterSpacing: 0.04em`) for status indicators, micro-metrics, and table headers.

## Layout & Spacing

The system runs on an 8pt base grid with an intentional 12-column responsive fluid configuration:

- **Desktop (1280px+):** 12 columns, 1.5rem (24px) gutters, 2rem (32px) margins. Maximum central operational canvas capped at 1440px for wide layouts.
- **Tablet (768px - 1279px):** 8 columns, 1.25rem (20px) gutters, 1.5rem (24px) margins. Sidebars collapse to icon-rail mode (64px width).
- **Mobile (< 768px):** 4 columns, 1rem (16px) gutters, 1rem (16px) canvas margins. Stack multi-pane panels into segmented screen flows or bottom-sheet overlays.
- **Density Rules:** Data tables, logs, and parameter lists favor condensed vertical spacing (`space-xs` to `space-sm`) to maximize visible state context without scrolling.

## Elevation & Depth

Visual hierarchy uses a combined model of **subtle hairline framing (`#E8E4E9`)** and **calibrated ambient drop shadows**. Glassmorphism is strictly confined to contextual navigation strips to avoid reducing legibility.

- **Level 0 (Base Canvas):** Background `#F8F6F7`. Completely flat, non-elevated ground layer.
- **Level 1 (Cards, Modules, Panels):** Background `#FFFFFF`, 1px solid border `#E8E4E9`, shadow: `0 1px 3px rgba(25, 23, 29, 0.04), 0 4px 12px rgba(25, 23, 29, 0.02)`.
- **Level 2 (Hover States, Interactive Cards):** Shadow transitions to `0 4px 6px rgba(25, 23, 29, 0.03), 0 10px 24px rgba(25, 23, 29, 0.05)`, border color transitions slightly to `#D5D0D7`.
- **Level 3 (Dropdowns, Overlays, Command Palette):** Background `#FFFFFF`, 1px solid border `#E8E4E9`, shadow: `0 12px 32px rgba(25, 23, 29, 0.08), 0 2px 6px rgba(25, 23, 29, 0.04)`.
- **Level 4 (Modals & Urgent Dispatch Dialogs):** Backdrop scrim `rgba(25, 23, 29, 0.45)` with subtle `backdrop-filter: blur(4px)`. Modal shadow: `0 24px 48px -12px rgba(25, 23, 29, 0.18)`.

## Shapes

The geometric rhythm strikes a balance between enterprise structure and modern touch ergonomics:

- **Corner Radii:** Base interactive controls, text fields, cards, and utility buttons use 0.5rem (8px). Larger operational widgets, modular dashboards, and system modals scale to 1rem (16px) or 1.5rem (24px).
- **Status Pills and Badges:** Fully rounded pill shapes (`9999px`) are reserved exclusively for contextual status chips, tag identifiers, and dispatch filters to clearly distinguish metadata from clickable action triggers.

## Components

### Buttons
- **Primary:** Background `#E84D96`, text `#FFFFFF`, border none, font `Inter` 500. On hover, background shifts to `#D23C83` with a subtle elevation shift. Focus ring is a 2px offset in `#E84D96`.
- **Secondary:** Background `#FFFFFF`, text `#19171D`, 1px border `#E8E4E9`. On hover, background shifts to `#F8F6F7` and border adjusts to `#D5D0D7`.
- **Tertiary / Ghost:** Background transparent, text `#302B35`. On hover, background shifts to `#F8E7EF` with text `#E84D96`.
- **Destructive:** Background `#C95765`, text `#FFFFFF`.

### Chips & Status Badges
- **Status Chip Format:** Height 24px, pill rounded, text `label-sm` uppercase.
- **AI Suggested / Automated:** Background `#F8E7EF`, text `#E84D96`, dot indicator `#E84D96`.
- **Resolved / Normal:** Background `#EBF5F1`, text `#27866D`, dot indicator `#27866D`.
- **Investigating / Queue:** Background `#FDF6EC`, text `#C58A32`, dot indicator `#C58A32`.
- **Down / Offline:** Background `#FBEBED`, text `#C95765`, dot indicator `#C95765`.

### Input Fields & Controls
- **Form Inputs:** Height 40px, background `#FFFFFF`, border 1px solid `#E8E4E9`, radius 8px, font `body-md`.
- **Focused State:** 1px border `#E84D96`, outward halo ring: `0 0 0 3px rgba(232, 77, 150, 0.15)`.
- **Checkboxes & Radios:** 16px square/circle, border 1.5px `#77727D`. When checked: fill `#E84D96`, checkmark `#FFFFFF`.

### Cards & Modules
- Clean `#FFFFFF` surface enclosed by a 1px `#E8E4E9` border.
- Header bars within cards have an optional bottom hair-divider `#E8E4E9` with uppercase `label-sm` category tags.

### Specialized AI & Campus Operations Elements
- **AI Insight Callout:** Card with `#FFFFFF` background, left border 3px solid `#E84D96`, and a 5% opacity `#F8E7EF` gradient wash.
- **Campus Metric KPI Block:** Large number (`display-hero` or `headline-xl`) in `#19171D` with subtle status trend badge pinned in the top-right corner.
